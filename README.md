# Itapemirim-BD

Modelagem de banco de dados relacional para uma empresa real de transporte rodoviário de ônibus (Itapemirim), desenvolvido como projeto acadêmico.

## Sobre o projeto

O projeto cobre o ciclo completo de modelagem de um banco de dados relacional:

- **Diagrama ER** — modelagem das entidades e relacionamentos do domínio de uma empresa de ônibus (rotas, viagens, passageiros, veículos, etc.)
- **Schema em PostgreSQL** — implementação do modelo lógico em tabelas, chaves primárias/estrangeiras e restrições de integridade
- **Inserção de dados** — povoamento do banco com dados de exemplo
- **Queries analíticas em SQL** — consultas para extrair informações e insights a partir dos dados modelados

## Tecnologias

- PostgreSQL
- SQL
